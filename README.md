# DaMark

Магазин одежды, белья и аксессуаров, который продаёт на эфирах в TikTok.

| Папка | Что это |
| --- | --- |
| [`link/`](link/) | Мультиссылка для профилей TikTok и Instagram: одна страница с кнопками на менеджера, группу наличия, TikTok и Instagram. Внутри TikTok и Instagram сама просит открыть её в браузере. В README — как закрыть общую группу в Telegram от мошенников. |
| [`app/`](app/) | Магазин с админкой: каталог, корзина, заказ с Новой почтой, Telegram-бот, закупки и прибыль. Пока закрыт паролем на https://new.damark.net. |
| [`deploy/`](deploy/) | Как это стоит на сервере и как обновлять. |
| [`shop/`](shop/) | Первый демо-шаблон (данные в браузере). Заменён `app/`, оставлен для истории. |

## На сайте

- **https://damark.net/** — только мультиссылка. Стоит на сервере `mcr`
  рядом с daon.pl; как выложить и обновить — [`deploy/`](deploy/).
  Пока полноценный сайт в работе, магазина на домене нет.

Старый адрес https://nexlyy.github.io/damark/ с любого пути перекидывает на
damark.net (`deploy/github-pages-redirect.html`, публикуется из `main`).
Варианты мультиссылки и демо-магазин живут только в репозитории: открыть
`link/variants/index.html` или запустить `npm run dev` в `shop/`.
