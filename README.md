# DaMark

Магазин одежды, белья и аксессуаров, который продаёт на эфирах в TikTok.

| Папка | Что это |
| --- | --- |
| [`link/`](link/) | Мультиссылка для профилей TikTok и Instagram: одна страница с кнопками на менеджера, группу наличия, TikTok и Instagram. Внутри TikTok и Instagram сама просит открыть её в браузере. В README — как закрыть общую группу в Telegram от мошенников. |
| [`shop/`](shop/) | Шаблон сайта с админкой и дашбордом: каталог, товары с фото и размерами, эфиры с номерами лотов, заказы, клиенты, закупки. Пока демо, данные хранятся в браузере. |

## На сайте

Каждое изменение в `main` само публикуется на GitHub Pages.

- Мультиссылка: https://nexlyy.github.io/damark/
- Каталог: https://nexlyy.github.io/damark/shop/
- Админка: https://nexlyy.github.io/damark/shop/#/admin
- Админка с примером: https://nexlyy.github.io/damark/shop/#/admin?demo=1

Картинка для превью ссылки в Telegram (`link/og.png`) указана полным адресом
`https://nexlyy.github.io/damark/og.png`. При переезде на свой домен адрес
нужно поменять в `link/index.html` и `shop/index.html`.
